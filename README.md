# Hospital Management System

## About the Project

This Hospital Management System is a command-line application developed in Python as part of my software engineering and Python learning 
journey.

The project began as a simple patient registration program and has gradually evolved into a modular application using Object-Oriented Programming (OOP)
and SQLite for persistent data storage.

My goal is not only to build a functional hospital management system but also to learn professional software development practices, database design, 
version control with Git, and application architecture.

##  Current Features

- Register new patients
- View all registered patients
- Search patients by Patient ID
- Update patient information
- Delete patient records
- Clear all patient records
- Automatic Patient ID generation
- SQLite database storage
- Input validation
- Modular Object-Oriented Architecture

## Technologies Used

- Python 3
- SQLite3
- Object-Oriented Programming (OOP)
- Git
- GitHub
